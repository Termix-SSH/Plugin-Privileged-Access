<h1>Privileged Access</h1>

<p>Ask for approval before anyone connects to a privileged host, with access that ends on its own and a full audit trail</p>

</div>

<br />

## Overview

Privileged Access turns chosen hosts into privileged hosts. Nobody opens an SSH or remote desktop session to one without approved access: they ask with a reason and the hours they need, an approver says yes or no, and the access ends on its own. With [Session Recording](https://docs.termix.site/plugins/session-recording) every privileged session can also be recorded and watched.

Read the [docs](https://docs.termix.site/plugins/privileged-access) to set it up and use it.

<br />

## Features

- Mark hosts as privileged, so SSH and remote desktop need approved access
- Ask for access with a reason, a ticket and how many hours you need
- Approvers say yes or no, never for their own request, and a host can name its approver roles
- Access ends on its own, and open sessions close when it does
- Break glass access for emergencies, always audited and alerted
- Every request and decision in the audit log, with a CSV report
- A dashboard card with requests waiting on you and your open access
